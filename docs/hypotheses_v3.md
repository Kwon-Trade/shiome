# 第3ラウンド A: 清算の連鎖の後の反発(ロング)— 条件と試行回数の記録

**記録した日: 2026-09-30。この文書を記録・コミットするより前に、5分足を使った計算(イベントの検出を含む)は一切していない。**
使うデータは2022〜2024年だけ。2025年以降の5分足はまだダウンロードしておらず、読まない。
結果を見てから条件を変えた場合は、元の記録を消さずに §11 に追記し、試行回数に数える。

## 1. 目的

清算(強制決済)の連鎖で急落した後、「連鎖が止まった」と判断できるところで買うと、平均でどれだけ戻るか。
「止まった」と判断する条件(合図)のうち、どれが一番良いか。

## 2. 期間

| 期間 | 役割 |
|---|---|
| 2022〜2023年 | 条件の形を決める |
| 2024年 | **1回だけ**確認する(見た後で条件を作り直さない) |
| 2025年以降 | 読まない。答え合わせに回すものは、結果を報告してからユーザーと相談して決める |

- 過去90日の分布が必要なので、実際に使えるイベントはおおむね2022年4月以降になる。
- 2024年を含む計算は1回だけ(第2ラウンドと同じく、2回目は止まる仕組みにする)。

## 3. データ

- **先物5分足**(新たにダウンロード、2022-01〜2024-12、第2ラウンドと同じ全389銘柄): 値段・出来高・テイカー買いの出来高。
- **現物5分足**(同、現物がある銘柄): 今回の条件では使わない(参考の保存のみ)。
- **建玉**: 手元の5分間隔データ(metrics の `sum_open_interest`、枚数)。
- **テイカー売買比率**: 5分足に含まれる「テイカー買いの出来高」から計算する(テイカー買い ÷ 全体)。
  手元の建玉データにも同じ情報の比率(`sum_taker_long_short_vol_ratio`)があるが、2022年初めなどに空欄があるため、足と時刻がぴったり揃う5分足の値を使う。
- 建玉は「その5分足が閉じた時刻までに記録されたもの」を使う(記録時刻 ≦ 足が閉じた時刻)。

## 4. 掃除(第2ラウンドと同じ + 5分足用)

- その日(UTC0時時点)に第2ラウンドの比較対象の条件を満たす銘柄だけ: 過去30日の1日平均出来高500万ドル以上、直前24時間に出来高ゼロの1時間なし、取引停止・上場廃止後でない、先物上場から7日以上。
- イベントの30分間(6本の5分足)に、足の抜けや出来高ゼロの足が1本でもあれば使わない。
- **極端なヒゲの確認**: イベントの30分間の出来高(USD)が、その直前24時間の「30分あたりの出来高の中央値」以上であること。
  本物の連鎖は出来高を伴うので、出来高の少ない一瞬のヒゲ(記録の誤りや板の薄さ)を外す。
- 買った後に上場廃止になった場合は、最後に取引があった価格で決済したものとする。

## 5. 連鎖(イベント)の定義

5分足が閉じるたびに(時刻 t)、直近30分(t−30分〜t)について次の3つを**すべて**満たしたら「イベント」とする。

1. **先物価格の下落**: 30分の値動き(t の終値 ÷ 30分前の終値 − 1)が、その銘柄の**過去90日**(t より前だけ)の30分の値動きの中で**下位1%以下**
2. **建玉の減少**: 30分の建玉の変化率(t の建玉 ÷ 30分前の建玉 − 1)が、その銘柄の過去90日の中で**下位1%以下**
3. **テイカーの売り優勢**: 30分間のテイカー買いの割合(テイカー買いの出来高 ÷ 全体の出来高)が **45%未満**(売りが55%以上)

- 過去90日の分布は、90日分の5分足のうち90%以上がそろっているときだけ使う。
- **同じ銘柄のイベントは6時間あける**(6時間以内の次の該当は数えない)。
- イベントの時刻 t0 = 条件を満たした5分足が閉じた時刻。**イベントの安値** = 30分の窓の始まりから、買う時刻までの最安値。

### 分類
- **市場全体の連鎖**: 次のどちらか。
  - BTCの同じ30分の値動きが、BTC自身の過去90日の下位1%以下
  - t0 の30分前〜t0 の間に、ほかの銘柄で**5銘柄以上**イベントが起きている(t0 までに分かる情報だけで判定)
- **その銘柄だけの連鎖**: 上以外。
- **グループ**: 大型(第1ラウンドと同じ10銘柄)/中型アルト/小型・ミーム(第2ラウンドと同じく、その日の過去30日平均出来高で残りを上半分・下半分に分ける)。
- **下落の大きさ**: 30分の値動きが −5%より小さい下げ / −5%〜−10% / −10%より大きい下げ。

## 6. 物差し(清算を伴わない下落)

- 5 の条件1(値動きが過去90日の下位1%以下)を満たし、**建玉の30分の変化率が0以上**(建玉が減っていない)場面。条件3(売り優勢)は問わない。
- 掃除・6時間あける・分類は同じ。
- 物差しにも同じ合図(S0〜S5)を当てはめる。主に S0(すぐ買う)同士で「清算を伴う下落の方が戻りやすいか」を比べる。

## 7. 「連鎖が止まった」の合図(買いの入り方)

イベントの5分足が閉じた後、6時間以内(72本)に合図が出た5分足の**次の足の始値**で買う。6時間以内に出なければ**見送り**(件数を示す)。
合図の判定には、その足が閉じた時刻までのデータだけを使う。

| 記号 | 合図 |
|---|---|
| S0 | 比較用: イベント直後にすぐ買う(イベントの足の次の足の始値) |
| S1 | 建玉の減少が止まる: 5分ごとの建玉の変化が**2本続けて0以上** |
| S2-15 / S2-30 / S2-60 | 安値の更新が止まる: イベントの安値(窓の始まりからの最安値)を、直近 **15分(3本)/30分(6本)/60分(12本)** の足で更新していない |
| S3 | テイカー売買比率が戻る: 直近15分(3本)のテイカー買いの割合が、**イベント前24時間**(窓の始まりより前の24時間)の5分足のテイカー買いの割合の**中央値以上** |
| S4 | 出来高が落ち着く: 直近15分(3本)の1本あたりの出来高が、イベント前24時間の5分足の出来高の中央値の**1.5倍以下** |
| S5 | 15分足で長い下ヒゲ: 15分足(毎時0・15・30・45分に始まる足)が閉じた時点で、下ヒゲ(始値と終値の低い方 − 安値)が足の値幅(高値 − 安値)の**50%以上**。その15分足が閉じた直後の5分足の始値で買う |
| S1+S2-30 | S1 と S2-30 が同じ足で両方成立 |
| S1+S3 | S1 と S3 が同じ足で両方成立 |

- S5 の15分足は、イベントの足が閉じた後に始まる15分足だけを見る。

## 8. 出す数字

合図ごと・期間ごと(2022年・2023年・2022〜23年・2024年)に:
- 件数、見送りの件数
- **1時間後・4時間後・24時間後の損益**(買値から、その時刻の5分足の終値まで): 平均・中央値・上位10%と下位10%の境目、勝率(損益 > 0 の割合)
- **戻りの最大幅**(24時間以内の最高値 ÷ 買値 − 1)と、そこに届くまでの時間(中央値)
- **買った後の最大の逆行幅**(24時間以内の最安値 ÷ 買値 − 1)と、**二段目の下げ**(24時間以内にイベントの安値を割り込んだ)の割合
- **コスト込みの損益**: 往復手数料0.10% + 片道スリッページ×2(その日の過去30日平均出来高で `configs/settings.yaml` の表から。板の薄い銘柄ほど大きい)。
  急落の最中は普段より板が薄いので、参考として**スリッページ3倍**の場合も示す(判定には使わない)。
- 分類別: 市場全体/その銘柄だけ、大型/中型アルト/小型・ミーム、下落の大きさ別
- 物差しとの差(同じ合図・同じ期間での平均損益の差)
- 平均損益の95%の幅は、週ごとのかたまりで引き直すブートストラップ(1000回)で出す(同じ週のイベントは市場全体の急落で固まりやすいため)。

## 9. 有望かどうかの目安(結果を見る前に決めた。答え合わせに回すかは最終的にユーザーと相談)

合図 × 持つ期間(1時間・4時間・24時間)ごとに、次をすべて満たすものを「有望」として報告する。
1. 2022〜23年と2024年の**両方**で、件数30件以上
2. 両方で、**コスト込みの平均損益がプラス**、かつ**コスト込みの勝率が50%超**
3. 両方で、物差し(清算を伴わない下落)の同じ合図より、コスト込みの平均損益が高い

### 事前に分かっていること
- **第1ラウンドの局面⑤「投げ売り後の底打ち」は不合格だった。** 条件は「24時間の値動き・建玉の変化・FRの7日平均との差がすべて極端に低い + 現物CVDが上向き」で、上がると予想した。
  - 2022〜2024年の24時間後の方向的中率: 大型 59.5%・中型アルト 59.0%・小型・ミーム 51.7%(件数 42・100・29)。
  - **2025年以降のデータでの判定**: 大型 47.1%・中型アルト 44.8%・小型・ミーム 34.2%(件数 17・58・38)で、基準を下回り不合格。
  - 今回の A は、同じく「建玉が減る急落の後に買う」考え方で、2025年以降の成績の一部をすでに見ている。答え合わせをする場合も、完全な初見ではないことを割り引いて考える。
  - 違い: 局面⑤は24時間・1時間足で判定したが、今回は30分・5分足で連鎖そのものを捉え、止まった合図を待って買う。
- 第2ラウンドでは、急騰・急落銘柄の「逆張り」(H3)は順位の上では効いたが、コストで消えた。今回もコストの影響が大きい可能性がある。
