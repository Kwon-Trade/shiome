# 第2ラウンド: 仮説と条件の記録(試行回数の台帳)

第1ラウンドでは「1銘柄が上がるか下がるか」を調べ、方向を当てられる指標は見つからなかった。
第2ラウンドでは問いを「**どの銘柄が他の銘柄より上がりやすいか**(銘柄間の比較)」に変える。

このファイルは、試した仮説と条件を**すべて**記録するためのもの。
あとで「何回試したか」を数えて、偶然当たっただけのものを見抜けるようにする。
結果を見てから条件を変えた場合は、元の記録を消さずに §9 に追記し、試行回数に数える。

---

## 0. 期間とデータの使い方

| 期間 | 役割 | 扱い |
|---|---|---|
| 2022〜2023年 | 仮説を形作る期間 | 仕組み作り・動作確認はここだけで行う |
| 2024年 | 確認用 | **最後に1回だけ**計算する。見た後で仮説を作り直さない |
| 2025年以降 | 答え合わせ用 | **一切読まない** |

- コードで強制する: `src/shiome/crosssection/data.py` の `HARD_END = 2025-01-01` より後は読み込み時に切り捨て、
  それ以降を要求されたらエラーで止まる。仕組み作りの間は `DEV_END = 2024-01-01` で2023年末までに絞る。
- 使うのは**ダウンロード済みのデータだけ**(先物1時間足・現物1時間足・ファンディングレート・建玉)。
- 先物の上場日は、手元データが始まる2022-01-01より前に上場した銘柄についてだけ、
  Binance公開データのファイル名一覧(中身は読まない)から調べて `configs/listing_dates.yaml` に記録した。

## 1. データの掃除

判断時刻 t(毎日UTC0時)ごとに、次のどれかに当たる銘柄はその日の比較から外す。
t の時点で使えるのは「t までに閉じた1時間足」(開始時刻が t−1時間以前の足)だけ。

| # | 除外するもの | 具体的なルール |
|---|---|---|
| 1-1 | 出来高ゼロの時間 | 直前24時間(t−24h〜t−1h)に出来高ゼロの1時間足が1本でもある |
| 1-2 | 上場廃止前の取引停止期間 | 最後に取引があった時刻より後(出来高ゼロが続く期間)。※1-1と必ず重なるので、ラベルとしてだけ使い、判定に未来の情報は使わない |
| 1-3 | 先物上場から最初の7日間 | t − 上場時刻 < 7日 |
| 1-4 | データの抜け | t−1h の足がない(Binance側のファイル欠け: 2022年2月26〜28日・4月1〜2日に一部銘柄) |

## 2. 比較対象の足切り(ユニバース)

- **過去30日の1日平均出来高(先物、USD建て)が 500万ドル以上**の銘柄だけを比べる。
  - 計算に使うのは t−30日〜t−1h の足だけ(その時点までのデータ)。
  - 基準額は**固定値**(時期によって変えない)なので、未来の情報は入らない。
  - 500万ドルにした理由: コスト表(`configs/settings.yaml`)で、これ未満はスリッページ(注文時の不利な価格ずれ)が
    片道0.25%以上に跳ね上がり、毎日入れ替える比較が現実的でなくなるため。成績を見る前に決めた。
  - 上場から30日未満の銘柄は「上場後の日数ぶん」の平均で判定する。
  - 30日の窓(上場後30日未満ならその日数)のうち、データがある時間が90%未満なら判定できないとして外す
    (2022年1月は手元データが30日分ないため、多くの銘柄が月末まで対象外になる)。
- その日の対象銘柄が **10銘柄未満の日は比較しない**(グループ別に見るときは5銘柄未満の日は比較しない)。

## 3. 判断時刻と値動きの測り方

- 判断時刻 t = 毎日 00:00 UTC。t の時点で全銘柄に順位をつける。
- 買う値段 = t−1h の足の終値(= t 時点の価格)。
- 期間 H = **24時間 / 7日 / 28日** の3通り。売る値段 = t+H−1h の足の終値。
- 期間の途中で上場廃止(取引停止)になった場合は、最後に取引があった時点の価格で決済したものとする。
- 売る時点の足がデータの抜けで無い場合は、その銘柄をその日の比較から外す。
- t+H が読み込み範囲の終わり(2024年分は2025-01-01、開発中は2024-01-01)を超える日は比較しない。
- 年の区分は判断日 t の年で分ける。

## 4. 仮説(6つ、細かく数えると8通り)

どれも「毎日0時に全銘柄を並べ、その後の値動きを比べる」。
「良い側」= 仮説がその後よく上がると予想する側、「悪い側」= その反対。

| ID | 仮説 | 並べる数値(t までのデータだけで計算) | 予想 |
|---|---|---|---|
| H1 | FR(資金調達率)が高いほど弱い | 過去7日(t−7日〜t)に確定したFRの合計 ÷ 7(1日あたりのFR)。確定時刻が t ちょうどのものは含めない | 高い → 悪い |
| H2-7 / H2-14 / H2-28 | 過去の上昇率が高いほど強い | t−(L+1)日 → t−1日 の値動き(L=7,14,28)。直近1日は除く | 高い → 良い |
| H3 | 直近24時間の上昇率が高いほど弱い | t−24h → t の値動き | 高い → 悪い |
| H4 | 建玉(OI)が増えた銘柄ほど弱い | 建玉(枚数)の7日変化率。t より前の最後の記録と、t−7日より前の最後の記録で比べる。どちらかが2時間以上古い記録なら計算しない | 高い → 悪い |
| H5 | 上場30〜90日の銘柄は古い銘柄より弱い | 上場からの日数。30〜90日未満=「新しい」、90日以上=「古い」。7〜30日は比較から外す | 新しい → 悪い |
| H6 | 先物の出来高が現物より多すぎる銘柄ほど弱い | 過去7日の先物出来高(USD) ÷ 現物出来高(USD)。現物データが無い銘柄、現物の足が90%未満の銘柄は外す | 高い → 悪い |

- 建玉を枚数で見るのは、USD換算だと値上がりしただけで建玉が「増えた」ように見え、H2と区別できなくなるため。
- FRは確定時刻の間隔(8時間・4時間など)が銘柄で違うため、1回あたりではなく「期間内の合計」で比べる。

## 5. 評価のしかた

各仮説を期間 H(24時間・7日・28日)ごとに計算する。

1. **勝率(いちばん大事な数字)**: 毎日、並べた上位20%と下位20%(各 max(1, 対象数×0.2を四捨五入) 銘柄)の
   平均の値動きを比べ、「良い側」が上回った日の割合。H5 は「古い銘柄すべて」と「新しい銘柄すべて」を比べる
   (新しい銘柄が1つ以上、古い銘柄が5つ以上ある日だけ)。
2. **順位の相関(スピアマン)**: 毎日、「並べた順位」と「その後の値動きの順位」がどれだけ揃っているか(−1〜+1)。
   予想の向きに揃うとプラスになるように符号をそろえ、全日の平均をとる。
   95%の幅は、日付をかたまりごとに引き直すブートストラップで出す。かたまりの長さは
   24時間・7日は**7日**、28日は**28日**(28日後の値動きは隣の日とほとんど同じ期間を含むため、
   7日のかたまりだと幅が狭く出すぎる。成績を見る前に決めた)。勝率にも同じ方法で95%の幅をつける。
3. **コスト込みの差**: 良い側を買い・悪い側を売る組み合わせを毎日作ったとして計算する。
   - 各日の組は H の日数だけ持ち、同時に持つ組は均等に割り振る(24時間なら毎日まるごと入れ替え)。
   - 毎日の入れ替え量(前日との持ち高の差)に、片道手数料0.05% + 出来高別スリッページ(その銘柄の過去30日平均出来高で決める。
     `configs/settings.yaml` の表)を掛けてコストとする。
   - 結果は「1日あたりのコスト込みの差(%)」で示す。コスト前の差も並べる。
   - 参考として、持ち高にかかるFRの受け払いも足した数字を別に示す(候補の判定には使わない)。
4. **年別**: 2022年 / 2023年 / 2024年、および 2022〜23年まとめ。
5. **グループ別**: 大型 / 中型アルト / 小型・ミーム(`historical_volume_groups()`、2022〜2024年の出来高による分類)。
   グループの中だけで並べ直して同じ計算をする。

## 6. 物差しとの比較(H1・H4・H6)

FR・建玉・先物/現物比は、単に「最近上がった銘柄」「値動きが激しい銘柄」を言い換えているだけかもしれない。
そこで、毎日の銘柄間の回帰(Fama–MacBeth法)で、その後の値動きの順位を
「調べたい数値の順位」+「H2-7・H2-14・H2-28・H3・過去24時間の値幅」の順位で説明し、
調べたい数値の係数(予想の向きをプラス)が、物差しを入れても残るかを見る。
係数の日平均と、§5と同じブロックブートストラップの95%の幅を示す。物差しを入れない場合の係数も並べる。
過去24時間の値幅 = (t−24h〜t の最高値 − 最安値) ÷ t の価格。

## 7. 答え合わせ候補の条件(結果を見る前に決めた)

期間 H ごとに、全銘柄での結果について次をすべて満たすものを「答え合わせ候補」とする。

1. 2022〜23年と2024年の**両方**で、順位の相関の平均が予想の向き(プラス)、かつ勝率が50%超。
2. 2022〜23年と2024年の**両方**で、コスト込みの差(1日あたり、FRの受け払いは含めない)がプラス。

候補には、2022〜23年の相関の95%の幅が0をまたがないか(偶然では説明しにくいか)と、
H1・H4・H6 については §6 で物差しを入れても残るかを並べて示す。
条件を満たさない仮説は、数字がどんなに惜しくても候補にしない。

## 10. 分かっている注意点

- **銘柄選びの偏り(生き残りバイアス)**: 手元の銘柄一覧は、2026年の出来高上位から選んだ銘柄と、
  上場廃止銘柄31を足したもの。2022〜2024年にBinance先物に実際にあったUSDT建て銘柄は
  年に約160〜380あったが、手元にあるのはそのうち63銘柄。
  「2026年に大きくなった銘柄」は、それまでの期間に値上がりした銘柄に偏りやすいため、
  銘柄同士を比べる今回の問いでは、結果がゆがむおそれがある
  (特に H5 の「新しい銘柄」: 2023〜24年に上場して2026年に大きくなった PEPE・SUI・WLD・ENA・TAO・ONDO など)。
- 2024-10-29 は、全銘柄に出来高ゼロの1時間(取引所側の記録の欠け)があるため、§1-1 により比較しない。
